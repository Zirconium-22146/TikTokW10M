# TikTokW10M

Клиент TikTok для Windows 10 Mobile (Lumia), который работает без Store:
тонкое UWP-приложение на C# + собственный сервис подписи запросов.

Репозиторий пока содержит только сервис подписи — он уже проверен на живом
TikTok и отдаёт ленту и видео. Клиент — следующий шаг.

## Зачем сервис, а не всё в приложении

TikTok подписывает каждый запрос к своему web API заголовками `X-Gnarly` и
`X-Dynosaur`. Алгоритм меняется: за год TikTok прошёл путь с 5.1 до 5.3.2.
Если зашить его в appx, каждая смена версии требует пересборки и переустановки
приложения на телефоне. Если держать его на сервере — достаточно редеплоя.

Сервис заодно ужимает ответы: сырой JSON ленты на 21 видео — около 450 КБ,
нормализованный — около 17 КБ. Для Lumia это разница между «листается» и
«умирает».

## Что уже работает

| Эндпоинт | Что делает | Состояние |
| --- | --- | --- |
| `GET /health` | состояние сессии и версии подписи | ✅ |
| `GET /feed?count=10&cursor=0` | рекомендации, прямые MP4-ссылки | ✅ |
| `GET /item?id=<id>` | одно видео по id (для ссылок и скачивания) | ✅ |
| `GET /raw?path=/api/...` | проброс любого API-запроса | ✅ |

Не завелось пока: поиск и профиль (`/api/search/*`, `/api/post/item_list/`,
`/api/user/detail/`) — TikTokу для них нужен ещё набор параметров, добиваем
через `/raw`. Логина, лайков и загрузки не будет: там аттестация устройства.

## Запуск

Нужен Node 22.18+ (умеет читать `.ts` без сборки).

```bash
cd signer
TOKEN=секрет node node.mjs      # http://localhost:8787
curl "http://localhost:8787/health"
```

## Деплой в Cloudflare Worker

```bash
cd signer
npx wrangler login
npx wrangler secret put TOKEN   # тот же секрет, что в клиенте
npx wrangler deploy
```

После деплоя клиент ходит на `https://tiktokw10m-signer.<аккаунт>.workers.dev`
с заголовком `x-token`.

## Структура

```
signer/
  signer.ts   алгоритм подписи (X-Gnarly 5.3.2 / X-Dynosaur, scm 2.0.0.561)
  tiktok.ts   сессия, подписанные запросы, нормализация — общий код
  node.mjs    локальный сервис
  worker.ts   вход для Cloudflare Worker
  wrangler.toml
docs/
  ARCHITECTURE.md
  API.md
```

## Ограничения

- Только просмотр: логин, лайки, публикация и комментарии недоступны.
- Версии подписи придётся обновлять (`SIGNER_SDK_VERSION` / `SIGNER_SCM_VERSION`).
- Датацентровые IP TikTok режет чаще домашних; лимит — один запрос примерно
  в секунду на сессию.
- Неофициальный клиент нарушает условия использования TikTok. Проект учебный.
